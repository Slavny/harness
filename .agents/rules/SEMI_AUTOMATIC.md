# Правила полуавтоматического режима работы (Semi-Automatic Mode)

Это соглашение между пользователем и ИИ-помощником для повышения эффективности разработки в проекте `harness-ai-app`.

## Принципы работы
1. **Анализ зависимостей до реализации**:
   - Прежде чем предлагать код, ИИ обязан проверить импорты, типы пропсов и связи между компонентами.
   - Код не должен требовать "доработки напильником" для запуска (импорты должны быть корректными).
2. **Проактивный контроль среды**:
   - ИИ должен самостоятельно проверять статус портов/процессов Tauri. Если виден конфликт (например, порт занят), ИИ должен предложить решение *до того*, как это станет проблемой.
3. **Атомарность изменений**:
   - Изменения группируются по связке (бэкенд + фронтенд + типы).
   - Изменения должны быть полными, чтобы система была в работоспособном состоянии после применения.
4. **Лаконичность и инициатива**:
   - Минимум лишних вопросов. Больше готовых решений.
   - Если требуется решение по дизайну — ИИ предлагает профессиональный вариант, соответствующий стандартам, и реализует его (при условии отсутствия возражений от пользователя).
