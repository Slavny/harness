# Harness AI App

Это настольное приложение, предназначенное для удобного взаимодействия с GigaChat API. Оно позволяет пользователям настроить подключение к GigaChat, используя свои API-ключи, и работать с моделью в комфортной среде.

![Приложение](Приложение.JPG)

## Статус разработки
Приложение находится в стадии **активной разработки** (Alpha/Beta). Функционал постепенно расширяется, возможны изменения в структуре и интерфейсе.

## Технологический стек
Приложение построено на современных технологиях для обеспечения высокой производительности и нативного взаимодействия с операционной системой:

- **Tauri**: Фреймворк для создания легких, безопасных и быстрых настольных приложений с использованием веб-технологий.
- **React**: Библиотека для построения пользовательского интерфейса.
- **TypeScript**: Язык программирования, обеспечивающий типизацию и надежность кода.
- **Vite**: Инструмент сборки, обеспечивающий быструю разработку и оптимизацию.
- **GigaChat API**: Интеграция с API от Сбера для работы с ИИ-моделью.

## Установка и запуск

Для запуска проекта убедитесь, что у вас установлены [Node.js](https://nodejs.org/) и [Rust](https://www.rust-lang.org/tools/install).

1. Клонируйте репозиторий:
```bash
   git clone https://github.com/Slavny/harness.git
   cd harness-ai-app
```

2. Установите зависимости:
```bash
   npm install
```

3. Запустите приложение в режиме разработки:
```bash
   npm run tauri dev
```

## Настройка
Для начала работы необходимо настроить API-ключ:
1. Запустите приложение.
2. Перейдите в настройки GigaChat API кликнув по шестерёнке слева снизу.
3. Следуйте инструкциям (создание проекта, получение ключа) и вставьте ваш ключ в поле ввода.
